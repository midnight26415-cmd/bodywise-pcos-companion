# PCOS Companion

A mobile-first PCOS lifestyle companion concept for tracking cycles, everyday symptoms, supportive habits, personal patterns, and questions for a care visit. PCOS Companion is an independent fictional prototype, not an official product of Be Bodywise or Mosaic Wellness.

## Open the app

GitHub Pages: https://midnight26415-cmd.github.io/bodywise-pcos-companion/

Open `index.html` locally for development. No build step, account, or backend is required.

## Included

- Daily symptom and habit check-ins saved by date
- Irregular-cycle journal with recorded cycle lengths and no 28-day assumption or ovulation prediction
- Pattern summaries based on sample and locally entered notes
- Printable or copyable 90-day doctor-visit summary
- Bite-size educational cards
- Responsive side navigation and touch-friendly controls
- Demo-only local email sign-in; no account or server authentication

## Privacy and scope

Fictional sample data is provided by default. Entries are saved only in the current browser's `localStorage`; there is no account sync or server. Browser local storage is not encrypted, so do not enter real personal health information. This prototype organizes notes only; it does not diagnose PCOS, interpret symptoms, recommend or change treatment, or predict fertility. It does not replace a qualified clinician. No payments are included.
